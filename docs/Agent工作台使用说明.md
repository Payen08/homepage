# AI Studio使用说明

开发者平台默认打开「AI Studio」，沿用现有浅色界面、紫色主按钮、圆角面板和任务对话方式。旧「插件开发」入口保留。

## 开始使用

1. 在首页直接输入消息。项目、设备都不选时直接聊天，无需先填写工作空间表单，也不自动生成文件或要求审查结果。
2. 项目和设备分别选择。项目下拉提供最近使用的项目、新建项目和无项目；点击新建项目后，关闭下拉并弹出仅填写项目名称的对话框；设备下拉独立选择一台设备，或不选择设备。
3. 选择项目后围绕该项目开发；选择设备后，任务关联一台设备，可在任务中查看、更换或解除。两项可分别取消，全部取消即回到直接聊天。
4. 文件、工具会话和实际任务按相应上下文保存，右侧工具面板初始收起。项目与聊天记录均来自实际创建行为。
5. 设备和 MCP 可在资源管理中建立演示连接；MCP 业务操作明确资源及权限，写入仍需确认。显式执行开发任务时，再展示执行步骤、文件差异和结果审查。
6. 左侧项目组以文件夹展示，点击展开或收起组内任务；组名旁常驻“＋”直接新建组内聊天，“更多”菜单也提供新建聊天、重命名和归档。顶部“新建聊天”始终从无项目、无设备开始；项目组旁“＋”或组内菜单的新建聊天保留当前组上下文。普通聊天在独立列表展示，不生成“聊天”文件夹。创建项目后即显示空项目组，无须先发送任务。
7. 开发任务沿用原工作台布局：左侧为对话、AI 分析反馈、任务规划、文件记录及完成反馈，底部保留 Build / Plan 选择，模型服务统一在系统配置中管理；右侧为代码变更和终端。文件差异支持统一 / 拆分、展开 / 收起、逐文件或批量接受 / 放弃，发生版本冲突时需要重新审查。
8. 即使已选择项目，发送“你好”等普通消息仍直接回复，不创建文件或开启审查面板。Plan 模式先讨论计划，切换到 Build 并提交实施指令后继续开发。
9. 左侧“＋”与输入栏项目菜单的“新建项目”使用同一流程：填写名称后，项目及同名项目组一并保存，自动选中该项目。以前从侧栏创建但没有绑定项目的空组，会在恢复数据时补上同名项目。
10. 查看开发任务：选中项目后提交开发需求，例如“开发设置页面”；左侧展示分析、规划、文件记录，生成差异后自动打开右侧代码变更。在任务开始前，也能点击右上角“代码审查”或输入栏下方“打开代码审查”查看面板；未生成差异时展示空状态说明。右侧直接提供代码变更、文件、终端三个标签。

## 已加入的功能

- 项目组：随项目创建，组织实际创建的任务，支持切换、重命名、归档和恢复。
- Agent 任务：按空间保存任务、对话、草稿、执行步骤、停止、继续、重试和归档。
- 资源连接：按任务新增、测试、查看、更换或解除设备连接；项目沿用当前任务的上下文。
- Skill：直接创建或从任务保存草稿、编辑 SKILL.md、标记可复用、下载及创建演示测试任务。
- MCP：接入与编辑服务、连接测试、启停工具、按任务授权业务资源、撤销权限。
- 操作审查：调用参数、实际目标、确认或拒绝操作、文件差异、版本冲突及历史记录。
- 系统配置：AI 模型与服务、权限规则、连接、布局密度、文字大小、用量记录及数据导出。
- 扩展中心：统一管理插件、MCP 和Skill，支持搜索以及系统默认、设备专属启停配置。
- 开发工具：工程目录树、新增文件与文件夹、删除与撤销删除、编辑保存、按聊天保留的终端会话、设备远程桌面演示。

## 数据与执行边界

- 未启用模型服务时使用本地演示回复；启用后模型回复与 API 测试使用真实请求。终端、设备、MCP 和远程桌面继续在本地演示，不发送真实业务或设备指令。
- 浏览器本地保存实际创建的空间、任务、授权、文件、Skill 及会话；刷新恢复当前空间。执行中断的步骤由用户主动继续，已完成操作不重放。
- 每个任务最多关联一台设备，支持更换和解除；旧设备未执行步骤取消，已有终端保留原环境和输出。
- MCP 每次调用按当前连接与授权状态执行；移除关联后保留历史，但限制后续调用。
- 文件版本变化会使旧差异进入冲突状态，需要更新差异并重新审查。
- 确认任务结果只更新确认状态，不再次执行工具操作。

顶部统一为一行项目组 / 当前任务及操作入口。左上角按钮在所有窗口尺寸均可收起或展开项目组，平台导航底部也有独立收起按钮；手动选择保存到本地，刷新后恢复。窄窗口首次进入时默认收起，之后不按任务状态改动侧栏选择；开发工具在窄窗口以可关闭的浮层打开。

项目聊天与开发任务共用同一外框、留白、消息宽度和输入栏样式；聊天里开始开发只增加分析与执行内容。项目组内新聊天清空输入草稿，保留项目、开发工具面板开关和原终端会话，代码变更仅展示当前任务的记录。

基础逻辑回归命令：`npm run check:workbench`。覆盖聊天与项目隔离、空项目组、旧记录修复、项目切换、设备任务与终端绑定、文件冲突和幂等结果确认。另执行类型检查、生产构建及浏览器交互回归。

项目文件以 `.opencode`、`src`、`AGENTS.md`、`package.json`、`plugin.json` 等真实保存的模板文件初始化；旧项目补齐缺失文件，保留已有文件和历史差异。删除文件可撤销，刷新不会重新生成已经删除的模板文件。

点击“终端”直接创建或恢复当前聊天的会话。项目名称、聊天来源和工作目录分别标注；切换聊天时选择该聊天自己的会话，原会话目录和输出保持。界面移除预览和返回开放生态入口。

聊天输入栏不提供模型切换，模型服务统一在「系统配置 → AI 模型」管理；移除管理工作空间及重复关联项目入口。任务区提供 SSH 设备关联弹窗，测试为本地演示，密码不持久化。文字采用 #333333 / #666666 / #999999 层级，内容留白增加；平台导航折叠按钮位于企业管理员账户旁。

## 系统配置与扩展中心

「系统配置 → AI 模型」配置系统默认的模型推理服务。预设提供 DeepSeek、智谱 GLM、Qwen、Gemini、OpenRouter 与 Ollama；预设与下方服务商表单独立。选择预设不修改服务商表单；需要密钥的预设在独立弹窗中测试后使用。Ollama 可直接选择，再次点击所选卡片可取消。免费权益、试用额度和限流说明以预设中的服务商文档为准，不把所有预设都标为永久免费。

- 「测试服务商 API」真实发送一条短消息至所填地址，以 Chat Completions 响应验证接口，反馈认证、模型、额度、协议、网络及超时错误。测试不自动保存配置，修改字段会清除旧测试结果。
- 「保存配置」保存服务商、模型、API Key 的当前页面凭据与 Base URL。界面只显示这四项配置、连通性测试和保存按钮。后续请求使用新配置，进行中的请求保留原配置；停止后返回的过期响应不会触发工具。
- API Key 默认隐藏，仅保留在当前页面内存，切换其他服务不会携带此密钥；刷新后重新输入。密钥不进入 WorkbenchState、本地存储、数据导出或错误反馈。当前原型未接入生产级密钥托管服务。
- 保存并启用后，Agent 的模型回复调用真实 API。设备、文件及 MCP 工具继续采用当前原型的本地演示流程，模型不会直接执行它返回的文本。

「扩展中心」是独立导航，按插件、MCP、Skill分类，支持名称与关键词搜索、数量展示、独立启停和新增Skill / MCP 入口。界面参考列表式扩展管理，沿用工作台的紫色主色和中性灰文字层级。内置机器人开发插件聚合 3 项Skill和 2 项设备工具适配能力；设备与 MCP 执行仍是原型演示。

- 系统默认与每台设备的覆盖配置分别保存。切换扩展中心的设备只改变能力配置范围，不改变任务设备关联。
- 从已关联设备的任务进入时，默认展示该设备的能力配置；无设备时可查看系统默认。
- 停用插件会使包含的Skill及 MCP 暂不可调用，保留各子项原本的启停选择，重新启用插件后恢复这些选择。
- 调用执行前检查当前启停、连接、任务目标与资源授权；停用后限制后续调用，历史步骤、调用次数和授权记录保留，不重复执行。
- Skill可在原Skill编辑器中创建、编辑、测试。尚未选择项目时也可以从扩展中心创建草稿。

默认地址与预设依据：[DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/)、[智谱 GLM](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.7-flash)、[Qwen](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)、[Gemini](https://ai.google.dev/gemini-api/docs/openai)、[OpenRouter](https://openrouter.ai/openrouter/free)、[Ollama](https://docs.ollama.com/api/openai-compatibility)。

## 设备连接与应用偏好

已有设备的“关联”只选择当前任务的执行目标，不打开编辑表单，也不把离线设备伪装为在线。仅“新增设备连接”和“编辑”打开 SSH 表单，表单内不提供重复的设备列表返回行。设备工作组在侧栏标记“设备”；独立聊天关联设备后仍保留独立聊天结构。

“系统配置 → 连接”逐台显示设备、SSH 地址、关联任务数量及在线 / 离线状态，可单独连接或断联；提供连接超时与启动时自动连接开关。自动连接只恢复上次连接且未手动断开的已配置设备。设备连接与自动连接继续使用原型演示。编辑设备地址后取消旧连接的未执行操作，已有终端保留原环境，需新建会话才能使用新连接。

“应用与更新”提供产品分析开关，展示 AI Studio Web 0.1.0 与“Agent 运行时：随平台版本一起更新”。产品分析当前只保存用户偏好，未向外部服务发送统计数据。


系统文件夹包含「天工系统」「百川轻搭」「数字造机」「百川装机」，统一显示【系统】标识，能力由平台预置。系统文件夹内新建聊天默认继承对应能力，不提供能力选择或关联配置菜单。原有数据会自动补齐百川装机文件夹，任务记录保留。

聊天输入框内以高亮入口提供「/关联园区」或「/关联设备」。关联成功后，园区或设备名称移到聊天任务顶部，输入框恢复普通输入；点击顶部标签可重新打开选择窗口并切换关联。天工系统仅关联园区，其他三项系统仅关联设备。每个任务最多一个园区或一台主设备。

自建项目和独立聊天在输入框提供园区或设备关联入口，根据实际关联资源自动加载能力，不提供系统能力、关联配置或完成操作。园区加载天工能力；设备按所属系统及任务内容加载设备能力。切换资源时取消旧资源未执行的操作，系统文件夹始终继承平台预置能力。

园区选择窗口提供「新增关联」，可输入 URL、登录账号及密码，验证成功后从账号有权访问的园区中单选。已关联园区以标签显示，新增和编辑验证均叠加弹窗；密码不进入本地持久化。设备新增同样填写服务 URL、账号和密码，验证后选择设备，保存所属系统及连接信息以自动加载能力。历史验证标识及关联可恢复，过期会话须重新验证后才可调用。

内置系统能力在扩展中心统一管理启停和读写权限。只有管理员可以修改配置和业务内容，普通成员仅查询。设备能力使用当前任务绑定的设备 IP；离线、解绑或实际目标不一致时阻止后续调用，已有终端保持原执行环境。

设备能力目录复用「内容清单/接口清单.md」及「内容清单/知识库能力清单.md」，原型不访问真实设备接口。自建 MCP 在扩展中心的 MCP 分类内直接通过添加或编辑弹窗管理，不提供独立开发接入页面。

任务菜单支持直接删除任务，清理任务记录、授权、未审差异及专属终端，保留项目文件和已保存的 Skill。
