# 任务设备关联规则

每个任务最多关联一台设备。任务区左侧的「关联设备」入口支持查看、更换和解除关联，不更改任务所在项目。

新建设备连接填写 SSH、开发板型号、IP / Host、端口、用户名和密码。测试通过后才能保存并关联；配置任意字段变化后必须重新测试。当前前端原型提供明确标识的演示测试，未接入真实 SSH 网关，密码不写入本地存储。

更换或解除时，取消原设备尚未执行的步骤及待审设备修改，保留已完成操作和历史记录。项目文件差异及其他任务的设备关联保持不变。原终端会话保存设备、目录和输出，切换设备后打开匹配新设备的会话。

关联、替换、解除、测试失败、配置变化后重新测试、密码不持久化及项目隔离已纳入回归测试。
