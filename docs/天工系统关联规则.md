# 天工系统关联

当前版本实现原型流程与服务接入状态，沿用工作台的资源列表、弹窗、授权及审查样式。

系统文件夹预置平台能力，天工系统聊天的输入框默认显示「/关联园区」，不提供系统能力和关联配置菜单。关联成功后高亮名称显示在任务顶部，输入框恢复普通输入。点击顶部标签可重新打开「选择园区」窗口；自建项目及独立聊天根据关联资源自动加载能力，不提供手动能力选择。全局菜单不提供资源关联入口。

园区新增关联可输入 URL、账号和密码，关联列表与账号验证弹窗显示实际绑定的内网连接地址。通过账号验证后选择有权访问的园区。原型使用明确标注的示例账号 `demo` / `demo123`；`viewer` 使用相同示例密码且只有读取权限。它们不代表真实天工账号，验证过程不会请求内网。实际账号应等待认证服务接入。

设备与园区统一在列表中关联、解绑和编辑，设备不再有独立详情页。设备与天工园区标题右侧分别提供新增入口，列表底部不提供操作按钮。

每条资源内部按规范化 URL 与园区 ID 去重。忽略 URL 的尾部斜杠和页面 hash；不同园区分别保存，不同 URL 互不复用认证。同一组合再次关联复用资源记录；有效会话可以复用，重新登录后仍需检查账号的当前园区权限。

项目可以保存多个园区资源，每个任务最多关联一个已验证园区。项目只有一个可用园区时，新建任务可以沿用；项目有多个园区时，必须在园区选择窗口中选择一条，不能同时继承多条。更换园区会替换当前关联并取消旧园区未执行操作。读写权限沿用账号、成员角色及内置系统授权，不再单独选择本次目标或允许修改。新建绑定必须具有当前有效的账号验证会话，未验证或已失效的资源只能先验证再关联。每次调用记录 URL、园区 ID、资源 ID 与会话引用；账号权限、关联范围、目标园区、会话与数据版本均在执行前重新检查。修改需要审查差异并逐次确认，结果确认不重复执行，拒绝写入保留已完成的查询。

资源、关联、验证时间、权限摘要及示例业务记录可以本地恢复。历史关联保留已验证标识，会话失效与从未验证明确区分。账号密码不写入持久化状态、调用参数、导出或日志；原型登录会话只在内存中保留 30 分钟，刷新后需要重新登录。断开一条资源不会影响同 URL 下的其他园区，历史操作记录保留。

## 实际服务接入边界

天工系统、百川轻搭、数字造机与百川装机归入「内置系统能力」，前端仅展示只读名称、启停、读取业务数据、提交业务变更及连接状态。连接方式由平台统一维护。只有管理员可以修改配置和业务内容；普通项目成员可以查询已授权资源。当前原型角色由工作台上下文的 actorRole 提供，正式接入必须使用服务端认证角色。

当前「安全凭据与认证服务」「账号可访问园区列表」「可访问内网的 Agent 浏览器」均显示待接入。原型浏览器仅操作示例记录，不访问真实天工页面。资源关联和 URL 保存本身不会开放页面控制能力。

正式接入由服务端完成以下操作，接口地址与字段需以实际服务为准：

- 身份验证：接收账号密码，交由安全凭据服务加密保存，客户端只得到不透明的凭据引用和授权会话引用。
- 园区发现：基于当前账号会话读取有权访问的园区及实际读写权限，不使用客户端提交的园区列表作为授权依据。
- 浏览器会话：在能访问目标内网的浏览器执行环境中复用授权登录状态，并验证目标 URL 和园区范围。
- 受控操作：每次读取及修改均核验资源、园区、账号、任务授权及浏览器会话；修改验证审查记录、参数和数据版本并防止重复执行。

登录 Cookie、访问令牌和原始密码均由服务端管理。权限或会话改变后，未执行的旧操作需重新提交与审查；页面中展示的会话引用不能替代服务端鉴权。

关联配置列表的设备连接与天工园区标题右侧各提供新增入口，底部不再提供新增或取消按钮。新增设备和园区配置使用独立叠加弹窗。新增园区直接填写账号密码，验证成功后选择园区。园区列表的未绑定项统一显示“关联”，点击后直接弹出验证表单。编辑已有园区直接显示当前园区及账号密码，点击“验证并保存”完成验证和保存，不再经过空白园区或验证入口页。关闭后保留原列表及当前滚动位置。

关联弹窗不显示原型验证说明或示例账号填充按钮，示例凭据通过说明文档或对话提供。验证失败仅显示账号或密码错误，不在界面暴露演示密码。
