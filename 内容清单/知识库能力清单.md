百川集成控制系统 - 知识库总览

本知识库是墨影科技百川集成控制系统的完整技术文档体系，涵盖系统架构、开发指南、API参考等内容。

文档编写规范（读者原则）

本库文档的读者是
集成 / 运维 / 二次开发工程师与 AI agent
——带着问题来查答案。编写与更新时遵守：

只写当前状态
：现在时态；禁止日期叙事与行为主体（"某日做了……"、"我们"、"本次"）、禁止会话黑话（"档3"）。时间与过程叙事只进 git log、项目 PROJECT_STATUS.md、issue/MR

一次性事件只进 
09-问题排查案例

：已修复且对使用者透明的 bug 不进其他文档

skill 只沉淀通用规则
：机制与规则写成永远有效的条款，不点名具体一次性事件

不写辩护式说明
："此处不做 X 因为 Y"仅当读者真的会尝试 X 时才保留

单点记录
：同一事件/规则只在一个文档出现，其余位置用链接

09-问题排查案例

天工传参未透传问题
 - SCRIPT 指令 arguments 沿链路丢失，proto 缺专用字段

行为树执行结果未上传天工
 - 任务管理路径丢弃执行结果，proto 缺 result 字段

umipc 包 find_package 失败
 - BPM 组件拆包导致 config 引用缺失目录，CI 配置期失败

设备状态监测行为树触发现场急停
 - 现场无缘由急停，常驻行为树机械臂模式联锁触发 integrate module 急停 IO

Kinco 伺服 CSP 保持报 IIT 故障
 - Kinco FD 静止保持 20~40s 报 0x603F=0x2350，环参数被改乱致 I²t 累积，0x2FF0 出厂恢复（含 PDO 映射重铺）
